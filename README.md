# ACADEXA - Student Course Management System

## Overview

ACADEXA is a Student Course Management and Learning Progress Tracking System designed as a modern EdTech platform. It provides students with an interactive interface to explore courses, enroll in learning programs, track progress, access modules, and manage their profiles.

This project focuses on creating a professional and user-friendly frontend experience using HTML, CSS, and JavaScript with a modern Navy Blue and Emerald Green theme.

## Features

### Student Authentication

* Student Login page
* Student Registration page
* Form validation using JavaScript

### Course Management

* Browse available courses
* View course details
* Enroll in courses
* Access enrolled course information

### Learning Management

* View learning modules
* Track completed modules
* Continue learning activities

### Progress Tracking

* Course completion tracking
* Progress visualization
* Learning statistics

### Student Dashboard

* Overview of enrolled courses
* Learning progress summary
* Student activities

### Notifications

* Course updates
* Learning reminders
* Important announcements

### Profile Management

* View student details
* Update profile information

## Technologies Used

* HTML5
* CSS3
* JavaScript
